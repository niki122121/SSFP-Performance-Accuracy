# SSFP-Performance-Accuracy
Code for measuring performance, precision and error propagation for SSFP decimal library for the Noir zk programming language.

As well as an implementation of:
1) min-max data normalizatoin
2) zscore normalization
3) A small FCNN trained on MNIST entirely within noir (89% - 90% accuracy). It contains two hidden layers of 64 and 32 neurons each. The network use ReLU and softmax functions as well as standard gradient descent for training and weight updates.
